# Řemeslo středověku — kompletní současný balíček řemesel a assetů

Tento balíček sjednocuje aktuální návrh všech hráčských řemesel a všechny dosud
připravené provozní grafické podklady. Neobsahuje vnořené starší archivy; každá
sada je přímo rozbalená, má vlastní popis a lze ji samostatně zkopírovat do hry.

## Rozsah

- 13 plných světských řemesel se společnou hodnostní osou;
- 6 kratších pracovních drah;
- skrytá větev artefaktu a návratu;
- kovářství jako plná referenční grafická realizace;
- společný bezešvý Fog of War;
- plánovací dokument o 25 stranách a strojově čitelný hlavní katalog.

## Co je skutečně hotové

| Oblast | Stav |
| --- | --- |
| Návrh 13 řemesel | Hotový: uzly, zkoušky, specializace, mistrovské projekty a ikony |
| 6 pracovních drah | Hotový návrh a ikony |
| Kovářství | Předměty, stavy jakosti, minihry, UI, ImGui atlas, node editor a 2.5D kovárna |
| Ostatní řemesla | Návrh a hlavní ilustrace; provozní sprity a minihry ještě nejsou vyráběné |
| Skrytá větev | Hotový návrh podmínek a milníků; výklad zůstává nejednoznačný |

Kovářství proto není jednorázová výjimka, ale vzor dat, stavů, pracovišť,
minihry, výsledné jakosti a rozhraní pro další obory.

## Začni zde

1. Otevři `documentation/Planovany_strom_remesel_Remeslo_stredoveku.docx`.
2. Pro data hry načti `catalog/crafts_master.json`.
3. Pro kovářství pokračuj podle `integration/START_HERE.md`.
4. Úplný obsah a kontrolní součty jsou v `catalog/asset_manifest.json`.
5. Výsledek ověření balíčku je v `catalog/package_validation.json`.

## Zásadní pravidlo progrese

Postup není nákup schopností za body. Uzel se otevře teprve tehdy, když hráč
práci viděl, pochopil, prakticky provedl a prokázal. Chyby, jejich rozpoznání a
náprava jsou součástí učení. Kniha může předat znalost, ale nenahradí praxi ani
mistrovu zkoušku.
